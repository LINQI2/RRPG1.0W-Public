# RRPG Milestone A Definition v0.1

## Purpose

Milestone A 不是完整游戏版本。

它代表：

> 第一次证明 RRPG 核心循环成立的最小产品验证目标。

它验证的是产品价值，而不是内容规模。

------------------------------------------------------------------------

# Core Validation

## 1. Person Continuity

玩家需要理解：

-   自己管理的是具体人物；
-   人物经历会产生长期影响；
-   人物不是一次性消耗单位。

------------------------------------------------------------------------

## 2. Expedition Value

玩家需要理解：

Expedition 不只是战斗容器。

它承担：

-   风险；
-   决策；
-   临时成长；
-   后果。

------------------------------------------------------------------------

## 3. Return Value

返回 Village 不只是：

-   领取奖励；
-   菜单切换。

它应该体现：

-   人物回归；
-   共同体变化；
-   长期反馈。

------------------------------------------------------------------------

## 4. Village Meaning

Village 应证明：

它是：

-   共同体空间；
-   长期变化承载空间；
-   未来选择形成空间。

------------------------------------------------------------------------

# Out of Scope

Milestone A 不要求：

-   完整职业生态；
-   完整事件库；
-   完整地图系统；
-   全部建筑系统；
-   全部长期养成系统。

------------------------------------------------------------------------

# Boundary

本文件定义：

产品验证目标。

不定义：

-   技术架构；
-   固定开发顺序；
-   最终全部内容范围。
