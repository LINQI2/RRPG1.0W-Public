**问题90 生命周期更新（2026-09-18 WP-B Expedition Return Integrity｜Technical Verified）**

- **已按独立任务落实（本轮实测）**：原始 RunEndMode 所有权 = `VillageRuntimeBridge` 的 Return 会话状态（`_pendingReturnMode`，与 `_returnRecord` 同生命周期；由 `SetExpeditionPersonIds` / `DiscardExpeditionReturnRecord` / `ResetForTests` 清除），**不持久化、不进 SaveData、不新建第二套 Return Authority**；`ExpeditionUI.FinalizeReturn` 是唯一 Begin-or-Resume 入口（未完成 Record 永不重新 Begin），resume 一律沿用原始出口模式；SafeReturn / Retreat / Defeat 三条产品出口（`OnReturnToTown` / `RequestRetreatFromProgression` / `HandleProgressionReturnFromBattle` 与 Legacy `OnReturnFromBattle` 防御分支）只在 Return 真正 Completed 后执行完成态清理，且 `AdventureManager.IsActive == false` 不再绕过未完成 Return Transaction。
