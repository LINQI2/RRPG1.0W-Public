## 1. 身份锚点（Identity Anchor）

Herbalist 来自长期找药、辨药、采药以及对植物和基础药性经验的积累。Battle 二次创作不把它直接做成“奶妈”，而是把这种人生翻译为：**根据对象、手段与程度判断当前什么处理才正确。**

## 2. 战斗身份（Battle Identity）

> **适配：判断什么处理在什么状态下才正确。**

当前三个判断维度：

> **对象 × 手段 × 程度**

共同决定：

> **现在什么处理才正确？**

## 3. 母题 / 子题候选地图

### 对症｜对象需要什么？

- **轻重判断：**情况有多严重？
- **因症施治：**这到底是什么问题？

### 药性｜手段应该怎么用？

- **相性 / 同药异效：**这个手段现在最适合给谁？
- **药毒两面：**这个收益值不值得承担它本身的代价？

### 剂量｜应该用到什么程度？

- **单次剂量：**这一次到底用多少？
- **累积剂量：**已经用了这些以后，还要不要继续？

当前 Gate 已确认六个子题具有独立玩家问题；剂量相关内容 Placement 明确后移，不意味着第一阶段需要立即实现 Counter / History。

## 4. 起始牌 / Trait / 当前内容候选

- **Starter 强候选：**《苦药》
- **Trait：**开放
- **初期强候选：**《急救》《强心》
- **初期候选：**《调养》
- **中期候选：**《稳住》《猛药》《烈草》《祛症》《诊治》
- **后期：**剂量 / 过量 / 累积语言方向，不等于已有正式 Card。

Starter《苦药》的价值是用一个目标选择展示“同药异效”，并保证单人第一战拥有直接攻击出口；具体数值仍以 Excel 为准。

## 5. 构筑接口

Herbalist 当前向 Shared Deck 提供：

- HP；
- Status；
- Heal / Shield；
- 身体风险；
- HP / 身体状态向 Attack 或其它主动价值的转化；
- 对“风险是不是纯损失”的重新定义。

它的组合价值不只是给队友回血，而是让其它内容**敢采用原本更危险的策略**。

## 6. 构筑种子与体验候选

### 透支调理（强候选）

核心问题：

> 我还能不能再透支一次，并把危险重新控制回来？

体验骨架：

> 身体代价 / HP → 主动战斗价值 → 风险提高 → 调理 / 稳定 → 再次承担风险

当前最自然的体验是 **风险掌控**：

> 早期“掉血 = 危险”，成型后变成“我敢主动进入危险区，因为我知道怎么把它拉回来”。

发动机候选是 **转化 + 稳定**；是否真的形成有张力的循环必须由 Prototype 验证。

### 相性 / 剂量

当前是重要身份语言与未来 Build 候选，但不强行把每个母题都做成独立流派。

## 7. 内容阶段原则

### 初期

优先：

- HP；
- Ally / Enemy；
- 简单 Heal / Damage；
- 一项收益 + 一项清楚代价。

### 中期

开始引入：

- 重伤阈值；
- Status；
- 更高灵活性的自适应处理；
- 药毒风险交换。

### 后期

才考虑：

- 可变剂量；
- 累积剂量；
- Counter / Threshold；
- History / 过量。

不要因为现实药学存在“配伍 / 剂量”等概念，就强行提前扩系统。

## 8. 与 Cook 的边界

- **Herbalist：**对象、手段、程度是否适配；
- **Cook：**已有资源如何被选择、加工和高效利用。

Herbalist 不应大量操作 Card Cost / Hand 结构；Cook 不应大量通过身体症状决定处理方案。

## 9. 组合观察

- × 高风险内容：Herbalist 可以把身体代价重新定义成可控资源；
- × Hunter：Status / HP 变化可能制造新的机会，但不能退化成“有状态就加伤”；
- × Worker：空间变化可能重新分配谁最需要处理；
- × Cook：资源效率与适配可以自然组合，但也是当前最容易语义互吞的一组。

## 10. 原型验证 / 开放问题

1. 透支 → 调理 → 再透支是否真的有风险张力，而不是无脑自残回血？
2. 初始 Trait 当前保持开放；不要为了填模板强行做治疗 Trait 或 HP→Attack Trait。
3. 剂量 / 累积剂量是否值得新增 History、Counter、Threshold，必须等多个强内容共同需要。
4. 相性牌的灵活性本身必须计入强度预算；基础相性牌优先单一判断维度、两态。
5. Status 内容不能扩展成“一种异常一张钥匙牌”的工具包。

## 11. 当前边界

- Current：适配 Battle Identity；对症 / 药性 / 剂量三母题；六子题；《苦药》Starter；透支调理 Seed。
- 开放：Trait、剂量系统、最终风险数值、更多正式 Build。
- 禁止误解：Herbalist ≠ 纯治疗职业；“药很多效果”不是母题，核心是**匹配判断**。
