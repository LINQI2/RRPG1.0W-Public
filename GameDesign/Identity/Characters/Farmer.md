## 1. 身份锚点（Identity Anchor）

Farmer 来自长期耕作、播种、照料、收获和储备经验。Battle 二次创作不把 Farmer 简化成“高攻击职业”，而是保留其最核心的人生经验：**促成一个价值开始发展，并持续经营它，最后决定何时利用或兑现。**

## 2. 战斗身份（Battle Identity）

> **促成并经营成长过程。**

玩家使用 Farmer 时，核心不是“当前哪张伤害最高”，而是不断判断：

- 什么值得开始培养；
- 是否继续投入；
- 如何维持已有成果；
- 什么时候停止培养并兑现；
- 当前结果能否成为下一轮发展的条件。

当前 Attack 只是第一产品阶段最容易教学和验证的经营对象，不等于 Farmer 永久只能经营 Attack，也不建立抽象统一 `Growth` 资源。

## 3. 母题 / 子题候选地图

### 促生 / 播种
- 创造发展起点
- 创造发展条件
- 让原本没有发展的东西开始发展

### 培育 / 深耕
- 持续投入
- 深化
- 路径惯性
- 投入深度

### 照料 / 去芜
- 维持条件
- 清除阻碍
- 恢复发展
- 保护已有成果

### 接续 / 接茬
- 发展窗口
- 同对象承接
- 跨 Person 接力

### 应变 / 重组
- 止损
- 改向

### 收成 / 利用
- 时机
- 放大
- 转化
- 分配
- 部分使用

### 再生产 / 轮作
- 留种
- 结果变条件
- 多周期循环

这些母题描述的是经营成长的玩家问题，不要求每个子题在第一阶段都立刻拥有正式 Card。

## 5. 构筑接口

Farmer 当前向 Shared Deck 提供的主要开放接口：

- 当前 Battle Value 的成长 / 培养；
- “已经投入过”的发展窗口；
- 延迟兑现；
- 收获时机；
- 培养结果对后续 Card 价值的重估。

其它 Identity 可以利用 Farmer 已经创造出的高价值对象，但不应直接接管 Farmer 的“成长过程”本身。

## 6. 构筑种子与体验候选

### 培养 → 兑现（候选）

体验骨架：

> 投入 → 成长 → 继续贪成长或现在兑现 → 收获

当前最自然的优势曲线是 **扩张**，核心发动机是 **积累**，随后通过收成 / 转化完成兑现。

关键成型感：

> 玩家第一次明显感觉“我之前的投入已经让后续选择发生质变”。

这条 Seed 有较强内容支撑，但仍需 Prototype 验证节奏和收获窗口。

## 7. 内容阶段原则

第一阶段优先使用：

- 可直接看到的当前 Battle Fact；
- Attack 作为第一教学载体；
- 低认知成本的投入 / 成长 / 收获。

更深内容后移：

- 第二种经营对象；
- 更复杂的跨周期再生产；
- 需要 History / 多对象长期管理的实现。

## 8. 组合观察

Farmer 适合提供“已经被培养出来的价值”，再由其它 Identity 重新利用：

- 与 Hunter：成长价值 + 时机兑现；
- 与 Cook：积累出的价值 + 加工利用；
- 与 Worker：空间条件如果真实存在，Worker 可帮助维护 / 重构成长条件；
- 与 Herbalist：存在潜在的长期投入风险管理组合，但当前直接内容证据较弱。

以上均为开放接口，不是固定推荐配队。

## 9. 原型验证 / 开放问题

1. 成长速度是否足够可感知，又不会让战斗前期成为纯等待？
2. “继续培养”与“现在收获”的时机是否形成真实张力？
3. 《初芽》是否在未来第二经营对象出现后需要泛化；当前不提前泛化。
4. Attack 之外的第二经营对象必须由真实内容需求自然产生，不能为了对称强造。

## 10. 当前边界

- Current：发展 / 培养作为 Battle Identity；7 个母题结构；Attack 第一原型；培养→兑现体验方向。
- 开放：第二经营对象、最终数值节奏、更多周期内容。
- 禁止误解：Farmer ≠ “统一 Growth 资源职业”；Attack ≠ Farmer 永久唯一对象。
